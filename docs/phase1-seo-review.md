## Purchase context and future storefront

The existing button text Collect This Piece becomes View Physical Print only for the six selected artworks. No purchase URL is changed or duplicated in the editorial configuration. The brief context and thematic link are appended inside the existing Featured Artwork paragraph; the original description remains. No story section is removed, moved, or shortened.

Metadata, labels and copy are provider-neutral: there is no new dependency on Etsy-specific wording in the reusable architecture. The existing purchase URL remains the source for the CTA, so a future approved storefront transition can change the actual purchase destination without rewriting this SEO layer.

## Product verification limits

Direct checks of all six exact public Etsy URLs returned HTTP 403. This is an access limitation, not proof that a listing is missing, unavailable or sold out. The implementation therefore uses the owner-confirmed physical catalog status and visible artwork subjects only. It introduces no materials, dimensions, framing-inclusion claims, prices, ratings, discounts, availability, production or shipping promises. Mockups are explicitly described as display presentations. No Product/Offer structured data is added. Listing-specific options still need human review if those details are ever proposed for publication.
